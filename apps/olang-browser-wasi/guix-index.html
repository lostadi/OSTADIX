O · Guix

Interactive Guix inside a browser-owned Linux Wasm guest. No native helper.

Experimental; this interactive profile has not been run end-to-end. First start creates a 2 GiB logical disk in this browser origin. Keep this origin and browser profile to retain installations. Browser storage permission is not a backup: clearing site data or storage eviction can remove the disk.

Ready. Startup can take several minutes; command input unlocks when the guix> prompt appears.


  

    
    
    
  

  
At guix>, try install hello, package --list-installed, or repl.
    Type exit at that prompt to finish and save cleanly. Ctrl-D leaves a Guile REPL or ends the command session.

  
Downloads are restricted to the configured Guix mirror. Arbitrary Internet access and guix pull are not provided.
    A forced stop, crash or failed disk flush leaves state requiring recovery; it is never automatically erased.
