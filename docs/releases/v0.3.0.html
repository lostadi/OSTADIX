The annotated tag, rather than the preparation-base commit above, identifies the final release revision.

Ostadix-lang v0.3.0 is an advanced systems-research release of the hosted polyglot runtime, typed evidence/admission pipeline, local Information substrate, bounded native O-core implementation, and compatibility-preserving public workspace facade. It is not a production release and does not qualify the separate OSTADIX Alpha system release.

Included claims

  • The root o-lang package remains the authoritative runtime and command package. The new ostadix-api workspace member is a narrow, explicit public facade with an owned runtime and a closed OValue payload vocabulary.
  • Backend Catalog V5 binds optional Backend Morphism V1 profiles for all 30 canonical backends. Python, JavaScript, and Rust retain shadow-only profiles; the other 27 entries explicitly have none. Archival Catalog V4 identities remain frozen.
  • Graph V2 binds the complete typed fidelity assessment. Evidence and Admission V6 are current for unversioned analysis, coordinator/evaluator execution, CLI/MCP inspection, and Placement Admission V2.
  • Execution Intent V1 remains explicitly bound to Graph V1 plus Catalog V5. Graph V1, Evidence/Admission V5, Schedule Why V1, and prepared-fragment V1 remain archival inspection surfaces; there is no silent V5-to-V6 uplift.
  • Durable Hosted V2 roots carry the package-0.3 execution-authority marker. Markerless pre-0.3 roots, V1 prepared fragments, and signed leases carrying V1 placement-admission digests are rejected before current dispatch rather than migrated or relabeled.
  • Information Bridge V1 exposes eight explicit, lossy, bounded native metadata projections. Its records use private canonical-CBOR wire mirrors, have no generic Serde/JSON wire surface, and do not mint evidence, admission, capability, dispatch, trust, freshness, or resolver authority.
  • o-info head uses an existing-root, lock-free reader. MCP o_information_inspect invokes only the fixed local command with bounded argv, timeout, concurrent pipe limits, a cleared environment, strict sanitized output, and no logical state mutation.
  • The manifest-governed production root DAG validates 149 production files, 40 roots, and 174 explicit cross-root edges, including physical source overrides, compiled fragments, facade projections, layer descent, and multi-root cycle rejection.
  • O-core x86-64 asynchronous returns preserve arithmetic status flags while projecting away hazardous user control flags. The mode-0 evidence binds syscall FMASK entry behavior while leaving capacity-tight probe modes free of that diagnostic cost.
  • O-core M6A smoke failures can capture bounded QMP scheduler/thread/frame/RPC diagnostics only after a failure verdict is frozen. This does not change the guest runtime or convert the QEMU gate into hardware evidence.
  • The release source builder produces a deterministic, allowlisted ZIP from an exact Git revision with a canonical manifest, checksums, link closure, and archive self-verification.
  • Publication requires the tag-triggered Required CI aggregate, including all required portable QEMU gates declared by evidence/gates.toml, to succeed.

Explicit nonclaims

  • This release is not production-ready and does not stabilize every public item exposed by the root research crate. The narrower ostadix-api facade is the intended public workspace surface.
  • It is not OSTADIX Alpha qualification. The separate G0-G13 registry and its dependency rules remain authoritative for that name.
  • It does not establish a live distributed World, replicated Governor, WorldFS, network discovery, scheduler-selected placement, or physical multinode HGraph execution.
  • Hosted Placement V6 remains a bounded direct-node preview, not World membership, general graph migration, production enrollment/key management, or global exactly-once execution.
  • Information bridge records are descriptive metadata. Supplier-decoded records are untrusted; HGraph/Evidence metadata projection digests are not native graph/bundle identities; Hosted self-signature consistency is not signer trust, chain continuity, or currentness.
  • The Information reader's tested no-mutation boundary covers logical content, inode, mode, and mtime. Atime and concurrent hostile ancestor replacement are outside Information Reader V1.
  • Backend Morphism V1 profiles remain inspection-only shadow records, not enforced universal semantic-preservation proofs.
  • The C17 and Python editions implement documented subsets and are not feature-identical to the authoritative Rust runtime.
  • QEMU TCG and OVMF evidence is not physical-machine, KVM, physical-device, DMA/IOMMU, hardware-isolation, or arbitrary-topology evidence.
  • Supplemental hardware-dependent gates remain outside the required portable release aggregate.
