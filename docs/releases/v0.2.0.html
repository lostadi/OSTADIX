Ostadix-lang v0.2.0 is an advanced systems-research release of the hosted language, semantic-custody pipeline, bounded native implementation, and experimental local/distributed-supporting mechanisms. It is not a production release and does not qualify the separate OSTADIX Alpha system release.

Included claims

  • Typed recursive evaluator composition, OValue, OIR, execution plans, HGraph, and the readiness-driven executor are implemented in the authoritative Rust runtime. The ordered OIR path remains a differential oracle.
  • Execution intent V1, evidence V5, admission V5, and backend catalog V4 retain explicit distinctions between semantic identity, evidence, authority, admission, dispatch, and observation.
  • Hosted Placement V6 is an additive bounded direct-node preview. Hosted transport V1 and opt-in durable-session V2 remain distinct protocols.
  • Hosted V2 provides durable signed journals, bounded recovery behavior, request-only handles, explicit runtime ownership, and deterministic shutdown.
  • Information Kernel V1 provides experimental authority-free information records, immutable local roots, projection receipts, and signed offline delta packs.
  • Backend Morphism V1 provides experimental shadow-only profiles for bounded Python, JavaScript, and Rust crossings. It does not alter catalog V4, evidence, admission, placement, or dispatch.
  • The repository includes the authoritative Rust runtime, supported C17 subset, Python semantic reference, and the O-core freestanding compiler/kernel research path.
  • The release source builder produces a deterministic, allowlisted ZIP from an exact Git revision with canonical manifest, checksums, link closure, and archive self-verification.
  • Publication requires the tag-triggered Required CI aggregate, including every required portable QEMU gate declared by evidence/gates.toml, to succeed.

Explicit nonclaims

  • This release is not production-ready and does not promise every historical top-level Rust module as a stable public API.
  • It is not OSTADIX Alpha qualification. The separate G0-G13 registry and its dependency rules remain authoritative for that name.
  • It does not establish a live distributed World, replicated Governor, WorldFS, network discovery, scheduler-selected placement, or physical multinode HGraph execution.
  • Hosted Placement V6 is not World membership, general graph migration, persistent-actor migration, global exactly-once execution, or production enrollment and key management.
  • Information roots and projection receipts do not mint evidence, admission, placement authority, runtime availability, or World membership.
  • Backend Morphism V1 profiles are inspection-only shadow records, not enforced universal semantic-preservation proofs.
  • The C17 and Python editions implement documented subsets and are not feature-identical to the authoritative Rust runtime.
  • QEMU TCG and OVMF evidence is not physical-machine, KVM, physical-device, DMA/IOMMU, hardware-isolation, or arbitrary-topology evidence.
  • Supplemental hardware-dependent gates remain outside the required portable release aggregate.
