Compiler contract

@transparent applies only to a brace-style structure with one direct primitive integer field: u8/u16/u32/u64, i8/i16/i32/i64, or usize/isize. Its field offset is zero and its size and alignment equal that integer. Zero or multiple fields, nested wrappers, arrays, pointers, Boolean and float fields, @packed, and explicit @align combinations reject.

The structure keeps its nominal identity in HIR, MIR and callbacks. Copying, locals, statics, arrays, control-flow merges, and internal arguments/results are admitted. Only the O-core internal ABI transports the wrapper by value. C/SysV, syscall, assembly, and wire boundaries retain primitive signatures. There are no implicit conversions, direct casts, or automatically inherited arithmetic, comparison, bit, shift, or atomic operations, including in unsafe source. Representation queries do not change source assignability.

@opaque records the canonical defining module. Only that module constructs literals or reads, writes, or takes field addresses. The rule also covers constants, statics, and imported aliases after identity resolution. Copying an owner-provided value remains legal. The attributes are independent; an opaque aggregate without transparency keeps the old aggregate-call limits. Existing unannotated structures and general pub behavior stay unchanged.

Constants use explicit unseen/evaluating/ready dependency states. Forward and cross-module references resolve before statics consume them. Cycles diagnose; an actual zero value is never an unevaluated marker. Wrappers receive no implicit zero initializer. The owner supplies valid initial constants and checked status/output-pointer constructors. Null, invalid range and exhaustion fail before mutation; failure leaves the output unchanged. A maximum current value has no successor and never wraps to zero. Pointer safety requirements and unsafe declarations remain explicit.

Typed wrap/unwrap or equivalent representation copies must validate width, identity, and call/result ABI. All three emitters must execute the admitted signed and unsigned widths, narrow normalization, stack arguments, indirect calls, and merges. Foreign imported NativeModule semantics are outside this change.

Independent lifecycle oracle

Write the policy model before using it to qualify the migrations. Keep domain, lease, block, network, transport and session limits distinct, with symbolic fresh sessions mapped to observed concrete tokens. Compare statuses, defined reply bytes, handles, fid/QID behavior, namespace contents, runnable/binding state and ordered effects against compiled production policy.

Pre-admission rejection, journalled platform rejection, exact retained replay, invalid historical requests, preparation and terminal failure are distinct. Retained replay precedes the current-epoch check; retry identity includes all request bytes and the tag. Read-only sequence zero is not mutation replay. An error can advance the journal without changing protected lifecycle state.

Separate finite profiles cover sessions, journal and replacement. State keys exclude predecessor traces/effects and retain bounded stale identities. Exhaustive means the reachable finite space was exhausted; bounded searches say so. Full-width production instructions and exact failure/effect ordering remain required. Candidate mutations must expose transport narrowing, wrap, missing owner/generation checks, session collisions, survivor revocation, premature runnable state, repeated reset/retry, and runner/evidence omissions.

Component carriers execute production policy on every implemented canonical target. Privileged-hook effects are recorded and explicitly modeled. Their results do not qualify physical hardware, SMP, or a full-system replacement. Fresh same-build AArch64 resident/restart/regression/provenance acceptance is separate and retains exact-pair admission and reviewed artifact identities.

Separate array-indexing change

Ordinary [T; N] indexing checks signed negativity and unsigned range, including empty arrays and zero-sized elements. Reads, writes, compound assignment and address-of share the rule. &array[N] traps; explicit unsafe pointer arithmetic remains the one-past route. Raw-pointer indexing keeps its unsafe, unchecked contract.

Capture base and index once in left-to-right order. Check an assignment target before its RHS and preserve divergence. A checked-element-address MIR operation is emitted in lower_place, retains the actual array type, derives layout, rejects offset/address overflow, and returns a typed element pointer. Every array layout is validated before use, including standalone, nested and pointer-to-array layouts. Malformed MIR rejects.

This is a language behavior change with its own diff, review and execution corpus. Real isolated traps and side effects must execute on x86-64, AArch64 and RV64GC. It is not folded into the identity migration.

Runtime implementation notes

The raw entry points retain one mutation body and their original rejection accounting. Typed internal calls extract or project identities at explicit storage boundaries. Shared capability lookup checks keep the exact owner, slot, state, generation, object-type and rights predicates. A nonzero cleanup key with no matching escrow still returns zero.

The new transfer mutation oracle has a dedicated real/stub leaf, selected only for Mode 13. Existing module choices and fixed linker limits remain in place. The live memory-view build fits those limits after removing redundant forwarding and sharing identical read-only capability predicates. Those changes alter generated instructions, with behavior checked by the mechanism and live gates.

The finite model distinguishes a provisioned namespace frontend from bound authority. After withdraw, restore, then withdraw before binding, the baseline can retain an active frontend with no bound session. Fresh baseline and candidate traces reject device activation and stale namespace access while the domain remains withdrawn and unrunnable. The model records that state rather than treating the active flag as authority.

The component carrier executes the production RAM-copy paths. Privileged reset and interrupt-interface hooks remain explicitly modeled; raw effects are retained. Its finite profiles exhaust 561 session states and 6,732 edges, 95 replacement states and 868 edges, and 63 journal states and 1,638 edges. Each edge has a shortest predecessor witness. The initial independent model covers O10 and namespaces; transfer and views use their compiled kernel oracles.
