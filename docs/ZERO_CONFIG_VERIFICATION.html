Compiler evidence from the user host

On macOS with the pinned Rust toolchain available, ./setup.sh --minimal compiled the dependency graph and reached the o-lang binaries. The compiler reported two E0382 ownership errors in src/bin/octl.rs: each expression moved resolved.address and then tried to borrow the partially moved resolved value to construct the TLS identity.

Both faults are corrected here by deriving tls_identity before moving the owned address into the client constructor. This preserves the same transport, identity, key, and timeout values and changes only evaluation order and ownership lifetime.
